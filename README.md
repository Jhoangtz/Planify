# Planify — Plataforma Inteligente para la Planificación de Viajes

Segundo corte: maquetación completa en **HTML5 y CSS3** (sin JavaScript todavía).

## Páginas
- `index.html` — Inicio (hero, buscador, destinos destacados, cómo funciona)
- `explorar.html` — Explorador de destinos (búsqueda, filtros por región, tarjetas)
- `detalle.html` — Detalle del destino con clima y pronóstico
- `favoritos.html` — Destinos favoritos
- `itinerario.html` — Itinerario por días y formulario de planificación
- `acerca.html` — Acerca de

## Estructura
```
index.html, explorar.html, detalle.html, favoritos.html, itinerario.html, acerca.html
css/styles.css
img/logo.svg
```

## Características
HTML semántico, diseño responsive (Flexbox y Grid), variables CSS, menú móvil sin JavaScript, formulario con validación nativa HTML5, foco visible y enlace "Saltar al contenido".

## Ver el proyecto
Abre `index.html` en el navegador (requiere internet para las banderas y las fuentes).
